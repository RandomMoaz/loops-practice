C++ Loops from Zero

A loop tells the computer: "do this job again and again." C++ has three kinds: for, while and do-while. Learn each one, watch them run step by step, then test yourself.

2 · The idea

Why we need loops

Without a loop

To print the numbers 1 to 5, you'd repeat almost the same line five times. For 1 to 1000 you'd need 1000 lines.

cout << 1 << endl;
cout << 2 << endl;
cout << 3 << endl;
cout << 4 << endl;
cout << 5 << endl;

With a loop

Write the job once. The loop repeats it and counts for you. Changing 5 to 1000 is one small edit.

for (int i = 1; i <= 5; i++) {
    cout << i << endl;
}

Think of doing 5 push-ups: you start counting at 1, before each one you ask "have I done 5 yet?", you do one, then you count up.

3 · The for loop

Loop #1: for, the counting loop

Hover or tap a colored part. Notice the three parts inside the brackets are separated by semicolons ;

for (int i = 1; i <= 5; i++) { cout << i << endl; }
1. StartMake the counter box. Runs only once, at the very beginning.
2. ConditionA yes/no question asked before every round. Yes: run the body. No: stop.
3. BodyThe job to repeat, between { and }.
4. UpdateChange the counter after each round, usually i++.
START (ONCE)Make the counter: int i = 1
ASKIs i <= 5 true? If no, the loop ends.
DORun the body once.
COUNTRun i++, then go back to ASK.

Use for when you know how many times to repeat: "print 1 to 10", "say Hello 3 times".

4 · The while loop

Loop #2: while, the "keep going while…" loop

A while loop has only a condition inside its brackets. It means: "while this is true, keep repeating." You make the counter before the loop, and you change it inside the body yourself. The colors match the for loop, so you can see where each part moved.

int i = 1; while (i <= 5) { cout << i << endl; i++; }
1. StartWritten before the loop. Runs once.
2. ConditionAsked before every round. False means stop.
3. BodyThe job to repeat.
4. UpdateInside the body. Forget it and i never changes, so the loop never stops.
BEFORE (ONCE)int i = 1;
ASKIs i <= 5 true? If no, the loop ends.
DORun the body, including i++.
REPEATGo back to ASK.

Use while when you don't know how many rounds you need: "keep doubling until the number passes 50", "keep asking until the password is right".

5 · The do-while loop

Loop #3: do-while, "do first, ask later"

A do-while loop runs the body first, and asks the question after. That means the body always runs at least once, even if the condition is false from the start.

int i = 1; do { cout << i << endl; i++; } while (i <= 5);
1. StartBefore the loop. Runs once.
2. BodyRuns right away, no question first.
3. UpdateInside the body, like in while.
4. ConditionAt the bottom. True: go back up to do.
Semicolondo-while is the only loop that ends with ;
BEFORE (ONCE)int i = 1;
DORun the body. No question yet!
ASKIs i <= 5 true? Yes: back to DO.
ENDNo: continue after the loop.

Use do-while when the job must happen at least once: show a game menu first, then ask "play again?"

  7 · Which one?
  
Same job, three loops

  
All three of these print 1 to 5. They do the same thing, just written differently.

  

    
for
for (int i = 1; i <= 5; i++) {
    cout << i << endl;
}

    
while
int i = 1;
while (i <= 5) {
    cout << i << endl;
    i++;
}

    
do-while
int i = 1;
do {
    cout << i << endl;
    i++;
} while (i <= 5);

  

  
The big difference: what if the condition is false from the start?

  
Here i starts at 10, and 10 <= 5 is false.

  

    
for (int i = 10; i <= 5; i++) {
    cout << i;
}

    i++;
}
Screen: (nothing). Runs 0 times.

    
int i = 10;
do {
    cout << i;
    i++;
} while (i <= 5);

  10 · Watch out
  
Common beginner mistakes

  

    
Commas instead of semicolons

      Won't compile
for (int i = 0, i < 3, i++)

      Fixed
for (int i = 0; i < 3; i++)

      
The three parts are always separated by ;

    
< or <= ?

      Shows 1 to 4
for (int i = 1; i < 5; i++)

      Shows 1 to 5
for (int i = 1; i <= 5; i++)

      
When i is 5, 5 < 5 is false but 5 <= 5 is true.

    
A semicolon after the brackets

      Shows "Hi" only once
for (int i = 0; i < 3; i++);
{
    cout << "Hi";
}

      
That ; ends the loop with an empty body. The block below then runs just once. Never put ; right after ).

    
Forgetting i++ in a while loop

      Never stops
int i = 0;
while (i < 3) {
    cout << "Hi";
}

      Fixed
int i = 0;
while (i < 3) {
    cout << "Hi";
    i++;
}

      
i stays 0 forever, so 0 < 3 is always true. This is an infinite loop.

    
Missing ; after do-while

      Won't compile
} while (i < 3)

      Fixed
} while (i < 3);

      
do-while is the only loop that needs a ; at the very end.

  






  Running it yourself
  
Where does this code go?

  
The examples above leave out the setup so you can focus on the loop. In a real program, put the loop inside main() like this:

  
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        cout << i << endl;
    }
    return 0;
}
