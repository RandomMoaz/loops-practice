Why do we need loops?

Imagine you want to print the numbers from 1 to 100. Writing cout one hundred times would be boring. A loop lets you repeat instructions while a condition is satisfied.

for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}

Output: 1 2 3 4 5

🔹 for

Use it when you usually know how many times you want to repeat.

🔹 while

Checks the condition first, then executes the loop body.

🔹 do-while

Executes the body first, then checks the condition. It runs at least once.

1. The for loop

A for loop has three parts: initialization, condition, and update.

for (initialization; condition; update) {
    // repeated code
}
for (int i = 1; i <= 4; i++) {
    cout << i << " ";
}

Flow: create i → check condition → execute body → update i → check again.

2. The while loop

A while loop checks its condition before executing the body. If the condition is false at the beginning, the body never runs.

int i = 1;
while (i <= 4) {
    cout << i << " ";
    i++;
}
⚠️ Remember to update the variable when needed. Otherwise, you may create an infinite loop.

3. The do-while loop

The body executes first. After that, C++ checks the condition. So it always runs at least once.

int i = 1;
do {
    cout << i << " ";
    i++;
} while (i <= 4);
Notice the semicolon ; after the while condition.

Important example

int x = 10;
do {
    cout << "Hello";
} while (x < 5);

Output: Hello

Even though x < 5 is false, the body runs once before the condition is checked.

4. break and continue

break

Stops the loop immediately and moves to the first statement after the loop.

for (int i = 1; i <= 5; i++) {
    if (i == 3) break;
    cout << i << " ";
}
Output: 1 2

continue

Skips the rest of the current iteration and starts the next iteration.

for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;
    cout << i << " ";
}
Output: 1 2 4 5
Easy way to remember: break = leave the loop. continue = skip this round.
